# AI Usage Policy

cms0 is intentionally human-led and AI-assisted. AI tools can help contributors
explore the codebase, draft changes, write tests, and improve documentation, but
they do not replace understanding, ownership, or review.

## Contributions

AI-assisted code and documentation are welcome when a human contributor remains
accountable for the result.

Contributors must:

- understand the change they submit
- verify correctness, security, accessibility, and performance where relevant
- run the checks needed for the affected surface
- disclose AI assistance in the pull request when it materially shaped the work
- keep generated output small, reviewed, and scoped to the issue being solved

Fully autonomous issue creation, pull request creation, review replies, or code
submissions are not accepted. Maintainers may close or ask for a rewrite of work
that appears to have been submitted without meaningful human review.

## Communication

AI may be used to draft, translate, or refine written communication, but final
comments should be the contributor's own.

Do not post large AI-generated explanations, reviews, or summaries as if they
were personal analysis. If AI-generated content is included for context, mark it
clearly and explain why it matters.

## Maintainer Review

Maintainers are responsible for what they merge and release. AI-assisted changes
should meet the same bar as any other contribution:

- clear intent
- small scope
- readable implementation
- tests or focused validation when needed
- no unrelated churn
- no secrets, private data, or unreviewed generated artifacts

## Enforcement

Maintainers may remove comments, request revisions, close pull requests, or
restrict participation when this policy is ignored.
