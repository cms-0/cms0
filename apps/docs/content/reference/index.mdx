## Main surfaces

- `@cms0/cms0`: app package, typed client, CLI, custom types, SEO helpers.
- `@cms0/admin`: self-hosted admin app and runtime API.
- Hosted workspace: organization, project, environment, endpoint, billing, and usage management.
