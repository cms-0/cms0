Add typed `.where()` and `.whereFirst()` query methods to the SDK client with full type inference. Supports structured filter operators (eq, ne, gt, gte, lt, lte, between, in, notIn, contains, startsWith, endsWith, isNull), dot-path nested field filtering, and AND/OR/NOT combinators. Works on both model accessors and root array accessors.
